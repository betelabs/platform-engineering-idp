# Onboarding a New Team to the IDP

## Prerequisites
- Team created in GitHub org
- Team lead has cluster access (speak to Platform team)

## Step 1 — Provision the team namespace

Run the onboarding script or apply the claim manually:

```bash
./scripts/add-team.sh --team <team-name> --environment staging
```

This provisions:
- Kubernetes namespace `team-<name>`
- ResourceQuota (default: 4 CPU, 8Gi memory)
- LimitRange (default container limits)
- RBAC: team gets `edit`, platform team gets `admin`
- NetworkPolicy: default-deny (generated by Kyverno)

## Step 2 — Register in Backstage

Add your team to `backstage/catalog/groups.yaml` and open a PR.
The catalog auto-syncs within 2 minutes of merge.

## Step 3 — Create your first service

1. Open Backstage → Create → **New Microservice**
2. Fill in service name, language, database requirements
3. Click Create — your repo, CI pipeline, and ArgoCD app are created automatically

## Step 4 — Done

Your team can now self-serve:
- New services via Backstage templates
- Databases via Crossplane claims
- Storage (S3/GCS) via Crossplane claims

For help: `#platform-support` Slack channel
